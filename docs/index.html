Recall is measured live against an exhaustive scan of all — vectors, run right after the graph search. It is the fraction of the true nearest neighbours the graph actually found.

The descent distance to the query, in visit order

Each dot is one node the search evaluated. Time runs left to right, distance runs bottom to top. The sparse upper layers cover the distance in a handful of hops; layer 0 is the dense cloud at the end where the beam refines the answer.

Graph layer populations, and how much of each was touched

These are toy embeddings. Each word is turned into a 64-dimensional vector by hashing its character 1-, 2- and 3-grams into signed buckets and normalising — no model, no training, no weights to download. So neighbours here are words that share letter sequences, not words that share meaning: night finds nights and knight, never evening. That is a property of the embedding, not of the index. Swap in real embeddings and nothing about the search changes — which is exactly the point: the index does not know or care where the vectors came from.

The vocabulary is every three-to-eight-letter entry in a public American English word list. Everything on this page runs locally in WebAssembly; the only network request is for the .wasm file itself.
